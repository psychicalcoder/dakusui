# ADR 0001: Record architecture decisions

Status: Accepted
Date: 2026-11-05

## Context

Reasons for design choices fade unless someone writes them down.

## Decision

We will record hard-to-reverse decisions as ADRs in `docs/adr/`.

## Alternatives

- Chat or commit messages: lost over time.

## Consequences

A little writing per decision. Rationale stays easy to find.
